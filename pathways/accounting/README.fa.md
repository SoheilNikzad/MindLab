# مسیر حسابداری

این مسیر مجموعه‌ای قابل ترکیب است، نه دوره‌ای با چهار جلسهٔ ثابت.

`GEN-PRM-101 ← ACC-PRM-101 ← ACC-DOC-201 ← ACC-OPS-210 ← ACC-REP-220`

برای طراحی دستیار: `SEC-AI-201 + ACC-OPS-210 ← ACC-AST-230`.

واحدهای DAT-DOC-201، UX-AI-201، KNW-RAG-220 و AUT-LOW-210 اختیاری‌اند. هیچ
واحدی مجوز ثبت نهایی، پرداخت، اظهار مالیاتی، نتیجه‌گیری حسابرسی یا ارسال دادهٔ
مشتری به مدل را ایجاد نمی‌کند. اجرای سازمانی به بازبین علمی مشخص، ضوابط حریم
خصوصی محلی و سیاست مصوب نگهداری شواهد نیاز دارد.
