# Accounting pathway

This pathway is a composable set, not a four-session course. Instructors may
select units by learner level and purpose.

## Suggested dependency graph

`GEN-PRM-101 → ACC-PRM-101 → ACC-DOC-201 → ACC-OPS-210 → ACC-REP-220`

`SEC-AI-201 + ACC-OPS-210 → ACC-AST-230`

Optional general units include DAT-DOC-201, UX-AI-201, KNW-RAG-220, and
AUT-LOW-210. No unit authorizes final posting, payment, tax filing, audit
conclusion, or disclosure of client data to a model.

## Selection examples

- Beginner literacy: GEN-PRM-101 + ACC-PRM-101.
- Document control: ACC-DOC-201 + ACC-OPS-210.
- Analyst track: ACC-DOC-201 + ACC-REP-220 + UX-AI-201.
- Assistant design: SEC-AI-201 + ACC-OPS-210 + ACC-AST-230.

These are examples, not fixed schedules. Institutional delivery requires a
named scientific reviewer, local privacy rules, and an approved assessment and
evidence-retention policy.
