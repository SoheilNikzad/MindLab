# Instructor guide — ACC-DOC-201

Before delivery, import the TSV with the same spreadsheet locale learners will
use. The single intended stated-versus-calculated discrepancy is row 8,
+50,000 rials.

Do not give the answer key before extraction. Check source transcription before
learners add formulas. Ask: “Which column is evidence, which is calculation,
and why?” The technical facilitator may fix delimiter, number-format, or formula
locale issues, but must not locate the discrepancy for the learner.

Prepare three fallbacks: paste TSV instead of upload; paired device use with an
individual explanation; printed unverified extraction when no model is
available. Live model use must be assessed later if it could not occur.

Stop the activity if real financial data appears. Never solve access problems
by requesting passwords, one-time codes, or “anyone with the link” sharing.
